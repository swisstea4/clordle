# Clordle
A wordle game but you don't know what the colors represent exactly.
## How to play
Play here: https://swisstea4.github.io/clordle

This is a Wordle variant where the rules are exactly the same as regular Wordle, except you don't know what the colours mean!
- You can only enter 5-letter words in English.
- After each guess, the tiles will change colour to either green, yellow, or grey.
- The meaning of the colours stays the same in between guesses: each colour can mean one of
    - You have the correct letter in the correct spot.
    - This letter is in the word, but in a different spot.
    - This letter is not in the word at all.
- Use the feedback from each guess to figure out what each colour represents.
